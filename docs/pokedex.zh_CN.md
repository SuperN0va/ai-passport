# 口袋图鉴

面向 AI Passport 的简体中文离线全国图鉴。开机先显示洛托姆风格像素 Logo，再进入独立设计的五入口首页，
不链接原有硬件测试菜单和视觉外壳；复用原工程 BSP。

## 功能与操作

启动页显示“口袋图鉴”，2.4 秒后自动进入首页；任意按键可跳过，且会消耗这次
按键的后续事件，避免同时误打开菜单。启动流程复用工作任务，不阻塞按键回调。
应用采用红、青、深蓝配色、掌机风格矩形面板和高对比选中态。18 种属性均有独立
符号与颜色，覆盖宝可梦列表、详情、图鉴说明、属性筛选、招式列表和招式参数。

- 收录全国编号 1–1025，每只一个默认形态、一张静态像素图。
- 中文名称、属性、首次登场世代、身高、体重、图鉴介绍和六项种族值。
- 编号检索（支持前导零）、名称拼音首字母检索（不区分大小写）。
- 世代与属性可组合筛选；双属性包含所选属性即可匹配。
- 收藏及最后打开的宝可梦保存到应用自己的 NVS 命名空间。
- 招式中文名、属性、威力、命中和基础 PP 按页面显示的游戏版本提供。
- 无需音频、网络连接、账号、触屏或在线服务。

上下键选择，按住连续移动；OK 打开或确认；长按 OK 返回。检索键盘提供数字、
字母、删除、查找。熄屏后的第一次按键只负责唤醒。无操作 30 秒调暗背光、90 秒
熄灭背光，USB 和按键仍可用。这不是深度睡眠，尚未测量实际续航。

从首页选择一个筛选条件，返回首页后选择另一个，即可组合筛选。“全部图鉴”清除
两个条件；收藏和检索也从无筛选条件开始。详情返回时恢复列表焦点。取消最后一项
收藏会进入明确的空列表状态。

## 数据与来源

可审阅输入为 `assets/pokedex/catalog.json`，其中记录来源提交、每条中文介绍的
来源及游戏版本，并独立存放物种世代和招式数据世代。生成的 C 表常驻只读 Flash。
版本规则为《朱／紫》优先（733 只），其余回退到最近有记录的前代作品
（Gen 8 为 283 只，Gen 7 为 9 只）；不合并同世代不同作品。

来源：

- [PokeAPI CSV](https://github.com/PokeAPI/pokeapi/tree/168b1e89467054cda2e7df43ccebbb69b459497a/data/v2/csv)：基础数据、名称、招式列表、招式历史变化和 722 条中文说明。
- [中文百科导出快照](https://github.com/42arch/pokemon-dataset-zh/tree/82ce04e611d19a12556c3955125b048b36187f52)：补充 299 条游戏图鉴介绍，原始来源为[神奇宝贝百科](https://wiki.52poke.com/)。多形态文本明确匹配；无法无歧义拆分的单元格回退到较早的明确条目。
- [NightCatSama 数据](https://github.com/NightCatSama/pokedex)：补充 #0417、#0496、#0651、#0652 四条说明；未能确定原游戏版本，页面明确标为“版本未标注”。已记录缓存文件 SHA-256。
- [Serebii 阿尔宙斯招式表](https://www.serebii.net/legendsarceus/attacks.shtml)：提供普通样式招式参数，不沿用常规 Gen 8/9 数值。迅疾／刚猛样式不在首版范围。
- [PKHeX 个体资料表](https://github.com/kwsch/PKHeX)：补入 PokeAPI 快照缺少的 492 条阿尔宙斯招式传授关系。目录记录确切提交，不嵌入 PKHeX 程序或应用代码。
- 图片和 LodePNG 来自参考 fork 的 `feature/ble-artwork`，提交 `6a049e2af6e560b7b92b2e5415a65a6d5a66c1aa`。图片为 48×48 RGB565 raw-DEFLATE，共 408,655 字节；最近邻放大为 96×96。保留 LodePNG 原许可声明。

当前目录包含 53,189 条去重关系、1,832 个招式／版本组合。未知或无固定数值显示
“—”，不写成 0，也不统一解释成必中。种族值与属性采用结构化快照口径，不随招式
数据世代变化。尚未在游戏内逐条独立验证所有内容及上游数据完整性。

宝可梦名称、图片和游戏文字属于各自权利人。导出项目的代码许可不代表所有第三方
素材均适用该许可；百科来源文本保留适用的署名及相同方式共享要求。工程记录来源，
不将这些资料标为原创。

## 数据再生成与字体检查

视觉源文件保存在 `assets/pokedex/`：`pocket-dex-logo.png` 是选定的透明生成 Logo；
`type-icons/` 包含固定版本 SVG、许可和参考色板。`visual-source.json` 记录来源与
PNG 哈希。属性符号是社区对游戏图标的复现，并非官方发布的素材包，详见
[资源说明](../assets/README.zh_CN.md#图片images)。

准备 `@resvg/resvg-js@2.6.2` 和 Pillow 12.3.0，运行
`python tools/generate_visual_assets.py --resvg <@resvg/resvg-js路径>`，可选传入
`--node <node路径>`。脚本导出 20/24 px 属性图标和最大 208×180 px、保持比例的
Logo，生成 RGB565A8 C 数组。数组常驻 Flash，ESP32 不解码完整原始 PNG。

`tools/import_pokedex.py --cache <缓存目录>` 读取固定 CSV、JSON、HTML，
不访问网络或爬取百科。脚本中定义缓存文件名。生成环境使用 Python 3.12、
pypinyin 0.55.0、beautifulsoup4 4.15.0；重新生成时应保留对应快照。

`python tools/generate_pokedex.py` 生成 C 数据表和字符清单。生成字体时额外传入
`--font <NotoSansCJKsc-Regular.otf>`、`--converter <lv_font_conv.js>`，
必要时传入 `--node <node>`。转换器固定为 `lv_font_conv@1.5.3`，生成 16/20 px、
未压缩 2-bpp 字库。FontTools 4.66.1 校验源字体 cmap，包含已知缺字的反向检查。
`assets/fonts/font-source.json` 记录字体哈希和参数，随附 SIL OFL 许可。

应用全部文字辅助函数显式绑定上述字库。启动时用 LVGL 实际字形查询逐一检查两个
字体的全部清单字符，拒绝占位符。实际硬件上的字形显示仍需要独立验收。

## 保存、内存与分区

LVGL 内存池为 48 KiB；检索键盘每个字符只使用一个带样式的标签。
快速双击 OK 按一次确认处理，避免连续跳过两个页面；检索使用姓名简拼，不提供完整中文输入法。

无需真机即可渲染实际 UI：准备锁定的 LVGL 9.5.0 源码，使用 CMake 构建
`tests/preview`，设置 `LVGL_SOURCE_DIR` 指向源码，并用 `CMAKE_BUILD_TYPE=Debug`
保留断言。运行 `pokedex_preview`，依次传入 `assets/pokedex/sprites.bin` 和已有输出
目录，生成 240×320 PPM 截图、检查编译后字库并进行两轮各 2000 次切页。
第二轮不得继续消耗内存，最小连续空闲块须大于 4 KiB。这不是 ESP32 性能测量。

Windows 下先执行 ESP-IDF 的 `export.ps1`，在 PATH 中准备本机 C 编译器和 Git Bash，
再运行 `bash tools/validate.sh`。固件阶段转交 `tools/validate_firmware.ps1`，使用原生
IDF Python/CMake/Ninja；失败构建保留诊断，成功构建先归档后清理临时目录。
Linux/macOS 继续使用原有 Bash 路径。

单个工作任务管理应用状态、保存和页面变化；按键回调只投递事件；绘制时持有 BSP
LVGL 锁。没有跨页面残留的定时器或生产任务。只解码当前精灵，96×96 RGB565 缓冲
占 18 KiB，列表只生成六个可见条目。NVS 使用带版本和 CRC 的单条记录，错误时不
擦除其他命名空间。写入失败保留待保存状态，下次交互时重试。

本应用主动保留 `0x10000` 起的 3 MiB 应用区、`0x356000` 设备标识区和
`0x700000` 工厂 Recovery。全部资源内嵌应用，合并固件必须在 `0x356000` 前结束。
同时保留上电按住 UP 五秒进入 Recovery 的旧入口。这是本应用的设计选择，
不是对当前上游所有衍生应用施加的默认分区限制。

校验后的合并固件可以从 `0x0` 写入，但其填充间隙可能重置 NVS/PHY；分段开发烧录
可保留这些间隙。两种方式都不写入设备标识或 Recovery 载荷，无需整片擦除。
烧录前仍须确认目标设备和确切固件，并取得本次刷机确认。
